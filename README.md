# ProjectSoft
Now squareVS.py contains:
- square(a): draws a square with given size of the side
- rotate(angle): draws a rotated square of a given angle
- polygon(sides, length): draws a polygon with given number and size of sides
- rotate_polygon(sides, length, angle): rotate turtle in order to draw an arbitrary polygon
- poly2(sides, length): replaces the sides of the polygon with an arbitrary serie of lines that scales with the size of the side
